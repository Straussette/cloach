Brancher Claude

Le coaching se passe dans ton Claude (claude.ai, appli mobile ou de bureau), sur ton propre abonnement. Ajoute Cloach comme connecteur, une seule fois :

  1. Ouvre claude.ai → Paramètres → Connecteurs, puis « Ajouter un connecteur personnalisé ».
  2. Nom : Cloach. URL :
  1. Clique sur « Se connecter » et entre ton e-mail et ton mot de passe Cloach.
  2. Dans une conversation, active le connecteur Cloach (menu « + » ou icône des outils), puis parle à ton coach.

Les boutons « Demander » de l'app ouvrent Claude avec la question déjà écrite.
